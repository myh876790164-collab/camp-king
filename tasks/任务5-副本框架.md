# 任务 5：副本系统框架
默认设计（第 1 步细化后写进 `tasks/副本设计.md`）：
- 每行驶约 300 公里（随机 250~350）出现传送警报，倒计时后和 3~5 个 NPC（从聊天室角色里抽）一起传送进副本，结束后回到公路原位置。
- 副本仍是横版，现实时间 3~6 分钟一场；玩家和 NPC 分别计分，结束按排名（第 1、前 3、参与、失败）发不同等级奖励。
- 通用目标：杀敌、跑完全程、存活；特殊目标按副本主题。奖励按主题设定。副本事件同步到聊天室。

- [x] 2. 触发与传送动画、副本场景切换（独立状态、存档兼容、退出回公路）
- [x] 3. NPC 参与者、计分、结算排名界面、发奖；用一个最简单的测试副本跑通全流程
