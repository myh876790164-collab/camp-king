# Camp King · 营地之王（v0.3 原型）

像素风营地建设游戏，五种模式。**双击 `index.html`** 用浏览器打开即可，不需要安装任何东西。

## 五种模式
| 模式 | 玩法 | 资源 | 胜负 |
|---|---|---|---|
| 1. 经典塔防 | 白天采集建设，夜晚守营地；科技树 + 每天三选一强化（含建筑联动） | 木材 石材 金币 | 营地被摧毁则失败，无尽挑战 |
| 2. 荒岛求生 | 模拟经营：给成员制作工具（木器/石器/铁器）、分配工作；成员有生命/饱食/心情/体力、技能和特质；海上来商船、落难船员、食人族 | 木材 石材 食物 铁 | 建成信号塔获救；全员死亡或营地被毁则失败 |
| 3. 丧尸求生基地 | 城市大地图（112×84 格，按真实城市规划：道路分级（高速/主干道/次干道/支路/小巷）、环岛、所有路口都是平面交叉（无高架桥）、铁路平交道口、红绿灯斑马线、停车场；功能分区：商务区、老城区、工业区、住宅区、河西郊区、城北农田）；开局从警察局、超市、医院、工厂、消防站、学校、加油站、公寓楼 8 种营地中选一个，各有禀赋；白天点建筑走到大门进入**内部地图**（按建筑类型生成户型：民居的客厅厨房卧室、医院的病房药房、超市的货架仓库……），点柜子、冰箱、箱子等容器搜刮，里面可能有丧尸；营地建筑内部可以摆放床位（每张床住 1 人）；招募有天赋词条的幸存者；幸存者面板含装备栏、天赋、技能、士气、数据；**异能系统**：变异丧尸掉落 15 种晶核，前 5 颗决定异能配比，之后服用对应晶核升级，27 种异能化学反应；**四档难度**（简单 / 普通 / 困难 / 噩梦）；营地同伴会主动迎战进入营地的丧尸、支援被攻击的建筑；**子弹**：枪械耗弹，靠搜刮、制作或警察局产出；**派驻分基地**：清空建筑后派同伴驻守，每天产出物资；每种营地建筑有独特产出；同伴白天会自己出门搜刮、天黑前回营地（能力越强带回越多）；枪声会引来丧尸；**中立商人**（第 2 天起随机来访，可买特殊装置图纸、子弹、急救包，可卖晶核）；夜晚守营地 | 食物 水 零件 | 避难所被攻破则失败 |
| 4. 极寒求生 | 类似经典模式，但熔炉要烧燃料；温度越低效率越低；暴风雪 | 木材 石材 煤炭 | 熔炉被摧毁则失败 |
| 5. 修仙门派 | 当掌门经营门派山头（主峰、宗主峰、炼丹峰、炼器峰、演武场、典籍峰）；每年正月开山收徒；弟子有根骨/神识/灵气/魅力四项属性；境界 凡人→筑基（百日筑基）→炼气（按功法采集 8 种天地真气并服下）→金丹（炼化真气结丹）→化神（体悟神妙诞生神通）→元婴（神通为元神、金丹为胚胎孕育元婴）；炼丹、炼器、演武、参悟、外出历练；随机机缘事件；天下五域与其他宗门只用文字记录 ；31 条道途（五行各五道：两天干一八卦两地支；三阳三阴）、七大职业（剑 术 符 丹 器 御兽 鬼）、道途精纯、物品道途属性、五行生克与阴阳消长 | 灵石 灵草 玄铁 灵木 | 有人修成元婴即胜利（可继续）；掌门死后无人继任则失败 |

## 操作
| 操作 | 电脑 | 手机 |
|---|---|---|
| 采集 / 选中建筑 | 点击 | 点击 |
| 建造 | 点底部按钮（或 1~9），再点空地 | 同左 |
| 移动视角 | 拖动 | 单指拖动 |
| 缩放 | 滚轮 | 双指捏合 |
| 丧尸模式移动角色 | WASD / 方向键，或点地面 | 点地面 |
| 科技 / 装备 | T / E | 底部按钮 |
| 暂停（存档、设置、回主菜单） | Esc | 右上角 ‖ |
| 加速 / 提前入夜 | 空格 / N | 右上角 ×1 / 「入夜」 |

存档：每天天亮自动存档（v0.3 地图变大，v0.2 的旧存档无法读取），也可以在暂停菜单手动保存（夜里不能存）。每个模式各一个存档位。

## 文件说明
| 文件 | 作用 |
|---|---|
| `js/modes/classic.js` 等 | **各模式的全部数值和规则**：建筑、科技、怪物、强化 |
| `js/config.js` | 公共数值（地图大小、升级倍率）、通用强化 |
| `js/sprites.js` | 像素画（字符画，每个字母是一种颜色；载入时自动放大 2 倍、圆滑边缘、加光影） |
| `js/map.js` | 地形生成、资源分布（地图 72×54 格，大小在 `js/config.js` 的 MAP_W / MAP_H） |
| `js/walls.js` | 墙壁自动拼接（横、竖、拐角、T 字、十字）和门（自己人能进出，敌人只能砸门） |
| `js/scavenge.js` | 同伴白天自动出门搜刮、回营地交物资 |
| `js/minimap.js` | 小地图（右上角）和大地图（点小地图或按 M） |
| `js/defense.js` | 同伴主动守营地、分基地夜袭 |
| `js/merchant.js` | 中立商人「精明的冬瓜」：随机来访交易、8 种特殊装置图纸（炮台 / 地雷 / 一次性大招） |
| `js/modes/sect.js` | 修仙门派：境界、真气、功法、丹药、差事、突破、机缘事件、天下大事、收徒、寿元（1 年 = 1 分钟；突破延寿按道途精纯、机缘、失败次数浮动；可开 ×20） |
| `js/sectdao.js` | 修仙门派的道途体系：31 条道途（五行×天干八卦地支、三阴三阳）、七大职业、契合度、神通生成、精纯度、物品契合、五行生克 / 阴阳消长 / 天干五合 |
| `js/sectskill.js` | 修仙门派的道途技能：每条道途 5 个（至少 3 个战斗技能），随境界领悟；战斗时自动挑 2 个施展，辅助技能常驻（含治疗同门、传道助修） |
| `js/sectfx.js` | 修仙门派的功法特效：31 条道途各有配色、修炼光环和施法特效（演武场施法、突破光柱、疗伤灵光） |
| `js/sectmap.js` | 修仙门派的山头地图、手绘殿宇图层、弟子小人；瀑布溪流、凉亭、石碑、竹林、梅树、香炉、冬季积雪 |
| `js/sectui.js` | 修仙门派的面板（弟子 / 典籍 / 天下 / 纪事 / 山峰）和地图特效（云雾、仙鹤、雨雪） |
| `js/outposts.js` | 派驻 / 分基地：每日产出、升级、夜间袭击；营地独特产出 |
| `js/abilityfx.js` | 异能增益清单、左上角增益条、每种异能独特的战斗特效 |
| `js/abilities.js` | 异能：15 种异能、晶核、配比觉醒、升级、27 种化学反应、15 种变异丧尸 |
| `js/interior.js` | 建筑内部：户型生成、家具和容器、室内战斗、营地床位 |
| `js/city.js` | 城市：建筑模型（代码画的像素画）、城市地图生成、路灯垃圾桶等街景 |
| `js/ground.js` | 高清地面：自然的地形边界、深浅水面、浪花、草丛花朵等装饰 |
| `js/pathfinding.js` | 怪物寻路（流场）+ 玩家寻路 |
| `js/entities.js` | 建筑、怪物、弹道、特效的通用行为 |
| `js/tech.js` | 科技研究 |
| `js/render.js` / `js/ui.js` / `js/scenes.js` | 画面、游戏内界面、菜单界面 |
| `js/save.js` / `js/audio.js` | 存档、音效、设置 |
| `js/input.js` / `js/main.js` | 操作、主流程 |

## 后续路线（建议）

- 打包：Windows（Electron/Tauri）、手机、微信/抖音小游戏（替换 `createCanvas`、`Store` 和输入层即可）
