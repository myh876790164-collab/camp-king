营地之王 · Windows 离线版
========================

【怎么玩】
  双击「开始游戏.bat」。游戏会在一个独立窗口里打开（用的是 Windows 自带的 Edge 浏览器），不需要联网。
  想要桌面图标：在「开始游戏.bat」上点右键 → 显示更多选项 → 发送到 → 桌面快捷方式。
  游戏开着的时候，也可以在任务栏的图标上点右键 →「固定到任务栏」。

【存档】
  存档自动保存在本机的 Edge 里，关掉再打开还在。
  注意：
  1. 不要移动或改名这个文件夹，否则游戏会以为是新的地方，找不到存档。
     要搬家的话，先在游戏「设置」→「导出存档备份」，搬完后再「导入存档备份」。
  2. 清理 Edge 的“浏览数据 / Cookie 和站点数据”会把存档清掉，清理前先导出备份。
  3. 网页版（Netlify 网址）和这个离线版的存档是分开的，可以用「导出 / 导入存档备份」互相搬。

【更新】
  有新版本时，把新的离线包解压后覆盖到同一个文件夹即可（存档不会丢）。
